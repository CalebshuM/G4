## 1. 登录与设备

### 如何登录 Canvas？
打开 https://canvas.ust.hk，选择正确的账号类型，使用完整的主邮箱地址（例如 account@connect.ust.hk）及密码登录，不能只填写账号名。登录问题按原文可联系 ITSO：cchelp@ust.hk，电话 2358-6200。

来源：PDF 第 2 页。

### 浏览器和电脑有什么要求？
使用能够运行较新浏览器的操作系统，并更新 Chrome、Firefox、Edge 或 Safari。浏览器需启用 Cookies 和 JavaScript。

来源：PDF 第 2 页。

### 手机可以使用吗？出现故障怎么办？
可以通过手机浏览器或 Instructure 官方 Canvas 应用访问，在应用中搜索 canvas.ust.hk，再使用 HKUST 账号登录。部分功能可能受设备限制。

排查顺序：更新应用 → 检查网络 → 清理缓存 → 必要时重新安装 → 改用浏览器或电脑。

- iOS：Settings → Canvas → 开启 Reset cache on next launch。
- Android：Settings → Apps → Canvas → Storage → Clear Cache/Data。

原指南建议，提交作业和参加测验，尤其是影响成绩的重要考核，应使用电脑。

来源：PDF 第 3–4 页。

## 2. 首页与课程管理

### 登录后首页有哪些区域？
Dashboard 汇总各课程活动与待办事项。Global Navigation 提供 Courses、Groups、Calendar、SFQ 和 Inbox 等入口；课程卡片可显示公告、作业、讨论和文件，具体可见性取决于课程导航设置；侧栏显示待办、即将发生的事件、成绩与 SFQ 请求；Help 提供指南和支持。

来源：PDF 第 2–3 页。

### 如何找到课程并设置收藏？
从左侧 Courses 选择课程；未显示时进入 All Courses。用星标收藏希望显示在 Dashboard 的课程。原文说明：未设置星标时，默认按字母排序显示最多 20 门课程；每学期可重新调整收藏。

来源：PDF 第 3–4 页。

### 已选课但找不到课程，如何排查？
1. 进入 Courses → All Courses，排除首页显示数量限制。
2. 若课程已在 All Courses，说明已成功加入该课程。
3. 若课程变灰、Published 为 No，说明教师尚未发布；联系教师确认。
4. SIS 选课信息每日同步，选课或退课后等待最多 24 小时。
5. 候补名单学生需正式选上后才获得访问权限。
6. 正式选课超过 24 小时仍缺失，向 canvas@ust.hk 提供课程代码和班别。

来源：PDF 第 4 页。

### 能看到课程但打不开，是什么原因？
课程可能尚未发布，也可能教师未选择使用 Canvas。向教师确认，并在 SIS 查询正式课程信息；同时检查浏览器和应用是否已更新。

来源：PDF 第 4 页。

### Canvas 日历为什么没有正式课表？
Canvas Calendar 显示 Canvas 课程的作业和事件。正式上课时间表应查询 SIS。

来源：PDF 第 4 页。

### 课程结束后还能访问吗？
课程结束后通常变为只读：可查看已发布内容，但不能继续提交或讨论。教师也可能取消发布材料或隐藏课程，具体情况向教师或助教确认。

来源：PDF 第 5 页。

## 3. 通知与页面故障

### 如何设置邮件通知？
通知可按类别设置为即时、每日、每周或从不，可采用全局设置或逐门课程设置。原指南建议公告使用即时通知。移动应用推送设置会覆盖浏览器设置，部分偏好可能不受应用支持。

来源：PDF 第 4–5 页。

### 页面提示 Disallowed Key Characters 怎么办？
依次更新浏览器、清理缓存和 Cookies、重启浏览器。若通过旧书签访问，改从 Canvas 主站进入目标页面。

来源：PDF 第 5 页。

## 4. 学习材料与作业

### Modules 是什么？
Modules 相当于课程目录，用于组织文件、页面、视频、考核和讨论等内容，可按周次、课堂或主题排列，具体结构由教师决定。

来源：PDF 第 5 页。

### 如何提交作业和多个附件？
在 Modules 或 Assignments 查找作业，也可能通过 Syllabus 或 To Do 的链接进入。打开作业后，点击右上方 Start Assignment，按作业要求提交。上传首个文件后，可点击 + Add Another File 添加其他附件。

来源：PDF 第 5–6 页。

### 重新提交会覆盖之前的作业吗？
能否重新提交由教师设置决定。允许重交时，教师可以查看所有已提交文件，学生只能看到最近一次提交。若误重交，应告知教师，因为教师可能只批改最新提交。

来源：PDF 第 6 页。

### 如何提交 Turnitin 作业并查看相似度？
教师配置后，直接通过 Canvas Assignments 提交，与普通作业流程相同；是否可交多个文件取决于设置。若允许查看报告，在作业右侧 Submission Details 中查找百分比形式的相似度图标。

来源：PDF 第 6 页。

### 如何上传和嵌入媒体？
在使用 Rich Content Editor 的位置，可上传并嵌入受支持的媒体文件。原文给出的上限为 500 MB；更大文件可放在外部平台（例如 YouTube）再嵌入。

来源：PDF 第 7 页。

## 5. 测验与成绩

### 参加测验前需要准备什么？
使用可靠电脑和稳定网络，更新 Chrome 或 Firefox，避免隐私或无痕模式，关闭多余标签页和窗口。熟悉题目导航与标记功能；仔细阅读时间限制、尝试次数、答案可见性、截止时间和锁定时间。

来源：PDF 第 7 页。

### 测验过程中需要注意什么？
关注计时器，通过题目导航与标记回看题目，避免同时打开多个测验标签页或窗口。完成后正式提交，离开页面不等于提交。若允许，可复查答案。Canvas 会记录测验活动；发生问题时立即联系教师或助教，各次测验规则可能不同。

来源：PDF 第 7 页。

### 在哪里查看成绩？
在 Dashboard 侧栏的 View Grades 查看各课程成绩汇总；进入具体课程后，通过左侧 Grades 查看该课程成绩。

来源：PDF 第 7 页。

## 6. 小组、沟通与第三方协作

### 在哪里找到小组空间？
可从课程首页右侧 Course Groups、课程 People 中的 Groups 标签，或全局导航 Groups 菜单进入所属小组。

来源：PDF 第 7 页。

### 如何自行加入小组？
进入课程 → People → View User Groups 或 Groups 标签，找到目标小组后点击 JOIN。

来源：PDF 第 8 页。

### 小组作业需要每人都交吗？
通常由一名成员代表全组提交即可；同时遵守教师对该作业的具体提交要求。

来源：PDF 第 8 页。

### 如何联系教师、同学或组员？
使用 Inbox（Conversations）与已加入课程中的人员交流。功能类似邮件，但原文说明没有抄送和拼写检查。需要即时邮件提醒时，将 Conversations 通知设为 Notify immediately。原文对 Inbox 位置的描述不一致，使用界面中标有 Inbox 的入口即可。

来源：PDF 第 3、8 页。

### Office 365 或 Google Drive 无法连接怎么办？
原指南要求重置对应服务的授权令牌（token）。Office 365 场景为 Collaborations 登录失败；Google Drive 场景包括 Collaborations 连接失败或提交 Google Docs 失败。原文只链接到排查说明，没有列出重置步骤；请通过来源链接查阅，本文不补造操作流程。

来源：PDF 第 8 页；具体帮助链接见来源链接.json。
